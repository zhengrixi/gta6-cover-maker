An offline web app that turns your photos and a caption into GTA 6-style multi-panel cover art — Vice City sunset and neon grades, bold caption lettering, several poster layouts — and exports a shareable PNG in common post sizes. Your photos never leave your machine.

## Run it

```sh
python3 -m http.server --directory app 8000
```
